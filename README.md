# Student Grading System in Python

## Project Description
This project is a simple student grading system developed using Python. It calculates student marks and assigns grades based on the marks obtained.

## Features
- Accept student details and marks
- Calculate total and average marks
- Display grades based on performance

## Technologies Used
- Python

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Run `Student grading system.py` using Python.
